# Import Birthdays WordPress Plugin

A WordPress plugin that allows administrators to import user birthdays via CSV file. This plugin works with the AutomateWoo Birthdays addon.

## Features

- Simple CSV import interface
- Progress bar showing import status
- Detailed success/error reporting
- Secure file handling
- Admin-only access

## Installation

1. Upload the `import-birthdays` folder to the `/wp-content/plugins/` directory
2. Activate the plugin through the 'Plugins' menu in WordPress
3. Navigate to Tools > Import Birthdays to use the importer

## Example CSV

```CSV
user_id,birthday
1,1990-01-15
2,1985-12-25
```
